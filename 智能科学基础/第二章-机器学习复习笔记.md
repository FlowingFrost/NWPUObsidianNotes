# 第二章 机器学习基础 — 复习笔记

## 2.1 概述

### 机器学习定义
- 对象是**数据(Data)**，提取特征→抽象模型→发现知识→分析预测
- 三要素：**任务T**、**性能P**、**经验E**
- 数据集 $D = \{x_1, x_2, \ldots, x_m\}$，每个 $x_i$ 是 $d$ 维特征向量
- 有标签时：$D = \{(x_1, y_1), (x_2, y_2), \ldots, (x_m, y_m)\}$

### 任务分类

| 维度 | 有监督学习 | 无监督学习 | 半监督学习 | 自监督学习 |
|------|-----------|-----------|-----------|-----------|
| 监督信号 | 人工标注标签 | 无监督信号 | 少量标注+大量无标注 | 数据自身生成伪标签 |
| 核心目标 | 分类、回归 | 聚类、降维 | 提升目标任务性能 | 学习通用表征 |

### 数据划分方法

**留出法 (Hold-out)**
- 2/3~4/5 训练，剩余测试
- 需多次随机划分取平均

**K折交叉验证**
- 数据分K个互斥子集，每次K-1个训练、1个测试
- 重复K次，对划分敏感性低

### 模型选择
- **泛化能力**：模型对未知数据的适应能力
- **欠拟合**：模型太简单，训练/测试误差都高
- **过拟合**：模型太复杂，训练误差极低但测试误差高

| 特性 | 欠拟合 | 过拟合 |
|------|--------|--------|
| 模型复杂度 | 过于简单 | 过于复杂 |
| 训练误差 | 高 | 极低 |
| 测试误差 | 高 | 高（远高于训练） |
| 典型原因 | 特征不足 | 复杂度过高、数据不足 |

## 2.2 回归与分类

### 2.2.1 线性/非线性模型

**线性可分**：可用线性函数（直线/平面/超平面）将两类样本分开
- 低维：直接看图
- 高维：检查**凸包**是否相交

**单元线性回归**：$f(x) = wx + b$，找一条直线使距离之和最小

**多元线性回归**：$f(x) = w^T x + b = w_1x_1 + w_2x_2 + \cdots + w_dx_d + b$
- 优点：简单、解释性好
- 缺点：不能拟合非线性数据

**逻辑回归**：将线性输出转换为概率
- Sigmoid函数：$f(z) = \frac{1}{1+e^{-z}}$，其中 $z = w^Tx + b$
- $z > 0$ → 正类，$z < 0$ → 负类，$z = 0$ → 0.5
- 优点：解释性强、计算量小
- 缺点：泛化能力差、容易欠拟合

**线性 vs 非线性**

| | 线性模型 | 非线性模型 |
|--|---------|-----------|
| 决策边界 | $w^Tx+b=0$ | 曲线/曲面 |
| 优点 | 简单、解释性强 | 能处理复杂关系 |
| 缺点 | 无法处理非线性 | 计算复杂、易过拟合 |
| 适用 | 线性关系、大数据 | 复杂非线性关系 |

### 2.2.2 决策树

**基本概念**
- 树形结构的if-then规则集合
- 根节点→非叶节点（测试条件）→分支（测试结果）→叶节点（分类标记）
- 遵循"分而治之"策略

**信息熵**

$$H(D) = -\sum_{k=1}^{K} p_k \log_2 p_k$$

- $p_k$ 是第k类样本占比，$H(D)$ 越小纯度越高

**信息增益**

$$IG(D, a) = H(D) - H(D|a) = H(D) - \sum_{v=1}^{V} \frac{|D_v|}{|D|} H(D_v)$$

- 信息增益越大，划分后纯度越大

**ID3算法**
1. 计算所有特征的信息增益
2. 选择信息增益最大的特征作为节点
3. 递归构建子树
4. 直到信息增益很小或无特征可选

- 优点：计算简单
- 缺点：倾向于特征数较大的属性，易过拟合

**剪枝**
- **预剪枝**：划分前评估，若不能提升验证集精度则停止（可能欠拟合）
- **后剪枝**：完整树自底向上检查，若替换为叶节点能提升精度则剪枝（训练开销大）
- 评估方法：验证集精度 = 正确分类数 / 总样本数

**随机森林**
- 集成学习（Bagging）：组合多个弱模型得到强模型
- 规则：
  - 每棵树随机有放回抽取k个样本
  - 随机选取m个特征子集（m << M）
  - 每棵树最大生长，无剪枝
  - 最终投票（分类）或平均（回归）
- 优点：准确率高、处理高维数据、评估特征重要性
- 缺点：噪声大时仍会过拟合

### 2.2.3 支持向量机 (SVM)

**核心思想**：找到最大分类间隔的超平面

**决策面方程**：$w^Tx + b = 0$

**点到超平面距离**：$d = \frac{|w^Tx_0 + b|}{||w||}$

**SVM优化问题**：

$$\min_{w,b} \frac{1}{2}||w||^2 \quad \text{s.t.} \quad y_i(w^Tx_i + b) \geq 1, \; i=1,\ldots,n$$

- 求解方法：拉格朗日对偶→KKT条件→SMO算法
- 凸函数性质保证全局最优解

**三种SVM**

| 类型 | 条件 | 方法 |
|------|------|------|
| 线性可分SVM | 严格线性可分 | 硬间隔 |
| 线性SVM | 非严格线性可分 | 软间隔（松弛变量） |
| 非线性SVM | 低维不可分 | 核函数映射到高维 |

- 优点：稀疏性（仅依赖支持向量）、计算效率高
- 缺点：严格线性假设、对噪声敏感、类别不平衡问题

### 2.2.4 人工神经网络

**生物神经元 → 人工神经元**

| 生物 | 人工 |
|------|------|
| 树突 | 输入层 |
| 细胞体 | 加权和 + 阈值 |
| 轴突 | 激活函数 |
| 突触 | 输出层 |

**M-P模型**（1943）：$f = \begin{cases} 1, & \sum w_i x_i \geq \theta \\ 0, & \text{otherwise} \end{cases}$

**激活函数**
- 线性函数：$f(x) = kx + b$
- 阈值函数（阶跃）：二值/双极形式
- Sigmoid：$f(x) = \frac{1}{1+e^{-x}}$
- ReLU：$f(x) = \max(0, x)$（解决梯度消失，计算高效）
- Tanh：$f(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$

**为什么需要激活函数**：没有激活函数，无论网络多深都是线性组合，无法解决非线性问题

**感知机**
- 单层：只能线性分类（AND、OR、NOT可解决，XOR不行）
- 多层（MLP）：加隐藏层可解决XOR

**前向传播**：输入→逐层计算→输出预测

**反向传播 (BP)**
1. 前向传播得到输出
2. 计算误差（损失函数）
3. 链式求导，梯度反向传播
4. 梯度下降更新权重：$w \leftarrow w - \eta \frac{\partial E}{\partial w}$

**梯度消失与爆炸**
- 消失：Sigmoid导数最大0.25，10层后 $0.25^{10} \approx 10^{-6}$
- 爆炸：权重>1时连乘指数增长

**卷积神经网络 (CNN)**

| 组件 | 作用 |
|------|------|
| 卷积层 | 局部特征提取（可学习的卷积核滑动） |
| 池化层 | 下采样（最大池化/平均池化），减少数据量 |
| 激活函数 | 非线性变换（ReLU等） |
| 全连接层 | 特征映射到分类空间 |

**为什么需要CNN**：
- 全连接参数爆炸（1000×1000 RGB → 3×10⁶×N 权重）
- 空间信息丢失（展平破坏像素空间关联）
- 平移敏感性

**残差网络 (ResNet)**
- 问题：深层网络退化（训练误差反而升高）
- 解决：shortcut connection（跳跃连接）
- 残差块：$F(x) = H(x) - x$，只需优化 $F(x) \to 0$ 而非 $H(x) \to x$

**UNet**：编码器（下采样提取特征）+ 解码器（上采样恢复分辨率）+ 跳跃连接

**RNN**：循环连接捕捉时序依赖，隐藏层输出反馈给自身

**生成对抗网络 (GAN)**
- **生成器G**：生成"假数据"骗过判别器
- **判别器D**：判断数据真假
- 对抗训练：G和D交替优化，最终G能生成逼真数据
- 应用：图像生成、文字转图像、超分辨率

### 2.2.5 贝叶斯分类器

**贝叶斯公式**：

$$P(B|A) = \frac{P(A|B)P(B)}{P(A)}$$

- $P(B)$：先验概率
- $P(A|B)$：似然
- $P(B|A)$：后验概率

**贝叶斯分类器步骤**：
1. 计算先验概率 $P(c)$：各类别在数据集中的频率
2. 计算似然 $P(x|c)$：某类别下各特征出现的概率
3. 计算后验概率 $P(c|x) \propto P(x|c)P(c)$
4. 选择后验概率最大的类别

**朴素贝叶斯**：假设所有属性相互独立（属性条件独立性假设）

$$P(c|x) \propto P(c) \prod_{i=1}^{d} P(x_i|c)$$

**半朴素贝叶斯**：适当考虑部分属性间的依赖关系

**贝叶斯网**：有向无环图，节点=随机变量，边=依赖关系，每个节点有条件概率表

### 2.2.6 结果评价

**错误率与精度**
- 错误率 = 分类错误数 / 总样本数
- 精度 = 1 - 错误率

**误差**
- 经验误差（训练误差）：训练集上的误差
- 泛化误差：新样本上的误差

**查准率与查全率**

| | 预测正 | 预测负 |
|--|--------|--------|
| 实际正 | TP（真正例） | FN（假反例） |
| 实际负 | FP（假正例） | TN（真反例） |

- **查准率** $P = \frac{TP}{TP+FP}$（预测为正的中有多少是真的）
- **查全率** $R = \frac{TP}{TP+FN}$（实际正例中有多少被预测到）

**P-R图**：查准率-查全率曲线
- 平衡点BEP：$P = R$ 时的取值，越大越好

## 2.3 聚类

### 概述
- **无监督分类**：无标签数据按相似程度分组
- 相似性度量：距离（欧氏、曼哈顿、切比雪夫）和相似系数（余弦相似度）
- 目标：簇内同质性高，簇间异质性高

### 距离度量

| 距离 | 公式 |
|------|------|
| 欧氏距离 | $d = \sqrt{\sum(x_i - y_i)^2}$ |
| 曼哈顿距离 | $d = \sum\vert x_i - y_i\vert$ |
| 余弦相似度 | $\cos\theta = \frac{x \cdot y}{\Vert x\Vert \cdot \Vert y\Vert}$ |
| 马氏距离 | $D = \sqrt{(x-\mu)^T C^{-1}(x-\mu)}$ |

### K-Means聚类

**算法流程**：
1. 选k个初始质心
2. 计算每个样本到质心的距离，分配到最近的簇
3. 更新质心为簇内均值
4. 重复2-3直到无新分配

**优缺点**：
- ✅ 简单快速、可扩展
- ❌ 对k值和初值敏感、不能处理噪声和离群点

### 层次聚类

**两种策略**：
- **凝聚（自底向上）**：每点一簇→合并最近→直到一簇
- **分裂（自顶向下）**：所有一簇→不断分裂→直到每点一簇

**簇间距离**：
- 最小距离（单链）：$D(C_a, C_b) = \min\{d(i,j)\}$
- 最大距离（全链）：$D(C_a, C_b) = \max\{d(i,j)\}$
- 平均距离：$D(C_a, C_b) = \text{avg}\{d(i,j)\}$

**特点**：不需预设簇数、可发现层次关系，但计算复杂度高、对异常值敏感

### 密度聚类 (DBSCAN)

**核心思想**：簇是高密度区域，被低密度区域分隔

**参数**：$\varepsilon$（半径）、MinPts（阈值）

**样本分类**：
- **核心点**：邻域内点数 ≥ MinPts
- **边界点**：邻域内点数 < MinPts 但在核心点邻域内
- **噪声点**：既不是核心点也不是边界点

**密度关系**：
- 密度直达：核心点邻域内的点
- 密度可达：通过密度直达链连接
- 密度相连：存在某点使两点都密度可达

**优缺点**：
- ✅ 不需预设簇数、能发现任意形状的簇、抗噪声
- ❌ 对参数敏感、密度不均匀时失效

## 2.4 降维

### 为什么降维
- 消除冗余、简化数据、提高计算效率
- 数据压缩、可视化
- 提取有效信息、丢弃无用信息

### 降维本质
学习映射函数 $f: x \to y$，其中 $\dim(y) < \dim(x)$

### 特征选择 vs 特征提取

| | 特征选择 | 特征提取 |
|--|---------|---------|
| 方法 | 从原特征中选子集 | 将原特征变换到新空间 |
| 结果 | 保留原特征 | 生成新特征 |

### 主成分分析 (PCA)

**目标**：找到方差最大的投影方向（无监督）

**流程**：
1. 数据中心化（减均值）
2. 计算协方差矩阵 $\Sigma$
3. 特征值分解，得到特征值和特征向量
4. 按特征值从大到小排序
5. 取前k个特征向量构成投影矩阵
6. 投影得到低维表示

**方差保留率**：$\frac{\lambda_1 + \cdots + \lambda_k}{\lambda_1 + \cdots + \lambda_d}$

**特点**：
- 每个主成分是原始变量的线性组合
- 主成分之间互不相关
- 无法描述非线性依赖关系

### 线性判别分析 (LDA)

**目标**：最大化类间距离，最小化类内距离（有监督）

**流程**：
1. 计算类内散度矩阵 $S_w$
2. 计算类间散度矩阵 $S_b$
3. 计算 $S_w^{-1}S_b$ 的特征值和特征向量
4. 取前k个特征向量构成投影矩阵
5. 投影得到低维表示

**PCA vs LDA**

| | PCA | LDA |
|--|-----|-----|
| 监督 | 无监督 | 有监督 |
| 目标 | 最大化方差 | 最大化类别可分性 |
| 投影方向 | 方差最大 | 分类最好 |
